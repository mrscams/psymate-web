Ajouter une spécialité

Créée active, placée après la dernière ; le code ne change plus et ne se supprime jamais.

Code : minuscules, chiffres et underscores, 2 à 40 caractères, commence par une lettre ; unique pour le type (sinon « Ce code existe déjà pour ce type »). Libellés : 120 caractères au plus.

Les modalités (au cabinet, en visio, à domicile) et les langues par défaut sont des listes fixes du contrat : affichées ici en lecture seule, non administrables. Une entrée désactivée disparaît aussitôt de « Mon profil public » et des filtres de l'annuaire ; les profils qui l'utilisaient encore ne peuvent plus être publiés tant qu'ils ne l'ont pas retirée.
