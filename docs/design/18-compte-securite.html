Ce compte a été créé depuis le serveur avec un mot de passe à usage unique, affiché une seule fois dans le terminal. Deux étapes sont obligatoires avant tout accès à /admin : choisir votre mot de passe, puis activer la double authentification.

  1. 1 Choisissez votre mot de passeRemplace le mot de passe temporaire.
  2. 2 Activez la double authentificationObligatoire pour les administrateurs, ne peut pas être désactivée ensuite.
Tant que ces deux étapes ne sont pas terminées, toute page d'administration répond « accès refusé » et vous ramène ici.

Aucun e-mail n'intervient dans cette procédure. Les deux opérations sont consignées dans le journal de sécurité.
